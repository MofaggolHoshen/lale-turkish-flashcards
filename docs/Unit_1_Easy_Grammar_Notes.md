# Unit 1: Easy Turkish Grammar Notes (A1)

This lesson explains each section in simple language with clear examples.

---

## 1) Demonstrative Words: Bu, Şu, O

These words are used to point to something or someone.

- Bu = this (close to me)
- Şu = that (close to you)
- O = that (far away)

### Easy explanation

We use these words like pointing words in English.

- Bu masa. = This is a table.
- Bu kalem. = This is a pen.
- Şu masa. = That is a table.
- O pencere. = That is a window.

### Questions with “Kim?” and “Ne?”

- Kim? = Who?
- Ne? = What?

### Example 1

- Bu kim?
- Bu öğretmen.

Meaning: Who is this? This is a teacher.

### Example 2

- O kim?
- O doktor.

Meaning: Who is that? That is a doctor.

### Example 3

- Bu ne?
- Bu kalem.

Meaning: What is this? This is a pen.

### Example 4

- Şu ne?
- Şu defter.

Meaning: What is that? That is a notebook.

### Important point

When you ask “who?” or “what?”, the answer is usually a noun.

- Bu kim? → Bu öğretmen.
- Bu ne? → Bu kalem.

---

## 2) Location Words: Burası, Şurası, Orası

These words are used to point to places.

- Burası = this place
- Şurası = that place (near you)
- Orası = that place (far away)

### Easy explanation

In English, we say “this place,” “that place,” etc. In Turkish, we say:

- Burası
- Şurası
- Orası

### Example 1

- Burası neresi?
- Burası sınıf.

Meaning: Where is this place? This is a classroom.

### Example 2

- Şurası neresi?
- Şurası bahçe.

Meaning: Where is that place? That is a garden.

### Example 3

- Orası neresi?
- Orası sokak.

Meaning: Where is that place? That is a street.

### Extra examples

- Burası ev. = This is a house.
- Şurası market. = That is a market.
- Orası Ankara. = That is Ankara.

### Important point

The word “neresi?” means “where is it?” or “which place is it?”

- Burası neresi? = Where is this place?
- Orası neresi? = Where is that place?

---

## 3) Plural Suffix: -lar / -ler

Turkish adds a suffix to make a noun plural.

- If the last vowel is a, ı, o, u → use -lar
- If the last vowel is e, i, ö, ü → use -ler

### Rule 1: Use -lar

- Kitap → Kitaplar = books
- Masa → Masalar = tables
- Kutu → Kutular = boxes

### Rule 2: Use -ler

- Kedi → Kediler = cats
- Öğrenci → Öğrenciler = students
- Pencere → Pencereler = windows

### Example 1

- Kitap → Kitaplar
- One book → many books

### Example 2

- Öğrenci → Öğrenciler
- One student → many students

### Important note

Numbers and quantity words do not usually take the plural suffix.

Correct:

- Üç çocuk. = Three children.
- İki kalem. = Two pens.

Wrong:

- Üç çocuklar. (incorrect)
- İki kalemler. (incorrect)

### Demonstrative plural words

- Bunlar = these
- Şunlar = those (near you)
- Onlar = those (far away)

### Example 3

- Bunlar çok güzel. = These are very nice.
- Şunlar öğrenci. = Those are students.
- Onlar kitap. = Those are books.

## 4) Question Suffix: mı / mi / mu / mü

This suffix is added to a sentence to make a yes/no question.

### Very important rule

This is not based on the last letter of the word. It is based on the last vowel of the word before the suffix.

This is called vowel harmony in Turkish.

### The rule is:

- If the last vowel is a or ı → use mı
- If the last vowel is e or i → use mi
- If the last vowel is o or u → use mu
- If the last vowel is ö or ü → use mü

### Easy pattern

| Last vowel of the word | Question suffix |
|---|---|
| a / ı | mı |
| e / i | mi |
| o / u | mu |
| ö / ü | mü |

### Examples with mı

- masa → Bu masa mı? = Is this a table?
- kapı → Bu kapı mı? = Is this a door?
- sınıf → Burası sınıf mı? = Is this a classroom?

### Examples with mi

- ev → Burası ev mi? = Is this a house?
- öğrenci → O öğrenci mi? = Is that a student?
- kedi → Şu kedi mi? = Is that a cat?

### Examples with mu

- doktor → Bu doktor mu? = Is this a doctor?
- kutu → Şu kutu mu? = Is that a box?

### Examples with mü

- gözlük → O gözlük mü? = Is that glasses?
- otobüs → O otobüs mü? = Is that a bus?

### Why this happens

Turkish follows vowel harmony. The question suffix changes to match the sound of the last vowel of the word.

For example:

- masa → last vowel is a → mı
- ev → last vowel is e → mi
- doktor → last vowel is o → mu
- gözlük → last vowel is ü → mü

### More examples

- Bu masa mı? = Is this a table?
- Bu kalem mi? = Is this a pen?
- O öğretmen mi? = Is that a teacher?
- Şu bahçe mi? = Is that a garden?
- Bu kapı mı? = Is this a door?
- O otobüs mü? = Is that a bus?

### Answers

- Evet, masa. = Yes, it is a table.
- Hayır, masa değil. = No, it is not a table.

### Example dialogue

- Bu dolap mı?
- Evet, dolap. = Yes, it is a cupboard.

- Burası ev mi?
- Hayır, ev değil, okul. = No, it is not a house, it is a school.

### Important point

This question form is used when you want to ask something with a yes/no answer.

The key idea is:

- Look at the last vowel of the word.
- Then use the matching question suffix.

This is one of the most basic and important rules in Turkish.

## 6) Easy Summary

This unit teaches basic Turkish grammar for beginners:

1. Bu / Şu / O = this / that / that
2. Burası / Şurası / Orası = this place / that place / that place

## 8) Beginner Tip

Learn the patterns, not only the words.

For example:

- Bu + noun = this is a noun
- O + noun = that is a noun
- Burası + noun = this is a place
- Bu + noun + mı? = Is this a noun?

This pattern helps a lot in speaking Turkish.

---

## 9) Quick Rule Reminder

Use the question suffix by the last vowel:

- a / ı → mı
- e / i → mi
- o / u → mu
- ö / ü → mü

Examples:

- masa → masa mı?
- ev → ev mi?
- doktor → doktor mu?
- gözlük → gözlük mü?

This rule is very important for speaking Turkish correctly.
